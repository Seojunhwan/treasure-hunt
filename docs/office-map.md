# 채널클랜 사무실 맵

업무석과 오른쪽 복도를 배치한 현재 맵이다. 기존 Kenney Furniture Kit(CC0)의 책상, 의자, 모니터, 키보드와 화분을 사용한다.

- 위에서 내려다보면 왼쪽 2×4석과 오른쪽 2×3석이 한 세트이며, 세로로 네 세트가 있다. 전체 56석이다.
- 사무실 남쪽 벽에서 정수기 쪽으로 치우친 반투명 미닫이문을 통과하면 길이 5m, 폭 6.6m의 통로가 라운지 입구 중앙으로 이어진다. 웜화이트 벽·천장과 밝은 베이지 바닥을 연한 민트빛 LED 띠 3줄이 감싼다. 띠는 진행 방향에 직각으로 1.25m 간격을 두고 놓여 있다.
- 라운지의 바닥 면적은 사무실의 1.5배다. 게임 좌표 기준 사무실은 약 41 × 53m, 라운지는 약 50 × 65m다. 통로 정면에 거울 기둥, 왼쪽에 8인용 식탁, 오른쪽에 카페가 있다. 중앙으로는 사방에서 계단을 내려갈 수 있고 안쪽 매점은 현수막 벽 양옆으로 이어진다. [라운지 구상](../라운지.md)
- 오른쪽 벽의 반투명 화장실 문은 닫혀 있다.
- 선물 후보는 책상과 통로의 76곳, 라운지의 4곳이다. 관리자가 게임을 시작하면 문제 수만큼 선택된다.

## 배치 바꾸기

- `shared/map.js`는 기본 게임 맵으로 `shared/maps/office.js`를 사용한다.
- `shared/maps/office.js`에서 업무석, 벽과 문, 바닥 소품, 라운지, 보물 위치를 정한다. `OFFICE_LAYOUT`은 모델을 그릴 때 쓰는 배치다. 게임에서 쓰는 위치와 충돌에는 같은 1.2 배율을 적용한다. NPC 위치와 상호작용 거리는 확대 후 게임 좌표를 기준으로 정한다.
- `client/src/game/office-world.js`가 기본 사무실을 그린다. 카펫과 사인, 책상 소품, 바닥 가구와 가전은 같은 디렉터리의 `office-decor.js`, `office-desk-details.js`, `office-fixtures.js`에 있다.
- 라운지의 계단·가구·보물 위치는 `shared/maps/lounge.js`, 거울·현수막·사인은 `client/src/game/lounge-decor.js`에 있다.
- 겨울 마을을 게임의 활성 맵으로 선택하려면 `shared/map.js`의 export를 `./maps/winter.js`로 바꾼다.
- `npm run dev`로 실행하면 맵이나 서버 파일을 수정할 때 서버가 다시 시작되고 진행 중인 개발용 회차가 초기화된다.

## 둘러보기

개발 서버의 `/office.html`에서 현재 사무실을 본다. `?view=passage`로 LED 통로 안쪽을 보고, `?view=mirror`로 기둥 거울의 반사를 확인할 수 있다. `?view=lounge`, `?view=desks`, `?view=entry`로 다른 구역을 바로 열 수 있다. **보물 위치 보기**로 80개 후보를 표시할 수 있다.

별도로 사무실 화면만 실행하려면 프로젝트 루트에서 `python3 scripts/preview-office.py`를 실행하고 `http://127.0.0.1:8766/office.html`을 연다. 이 경우 Three.js를 CDN에서 불러오므로 인터넷 연결이 필요하다.

`office-floorplan.svg`는 초기 콘셉트의 배치도다.
