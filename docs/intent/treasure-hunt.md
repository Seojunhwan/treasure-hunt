# 송년 보물찾기 게임 — 확정 기획 (Statement of Intent)

확정일: 2026-11-23

겨울 마을 V1의 기획 기록이다. 현재 사무실 버전의 기획은 [SPEC.md](../../SPEC.md)에 있다.

## 결과물
눈 내린 겨울 마을 3D 맵에서 하는 실시간 멀티플레이 보물찾기 웹 게임. 모바일 브라우저로 바로 접속.

## 사용자
- 사무실 동료 약 40명이 각자 폰으로 참가
- 관리자 1명이 노트북으로 진행 (사무실 큰 화면에 띄움)

## 게임 흐름
1. 참가자는 QR 코드로 접속, 닉네임만 입력 후 스폰 지역에서 대기
2. 관리자가 "시작"을 누르면 15분 동안 이동 가능
3. 조작: 화면 가상 조이스틱 + 3인칭 시점

## 규칙
- 어렵게 숨긴 보물 40개, 선착순 (먼저 찾은 사람이 가져가고 맵에서 사라짐)
- 보물은 모두 1점, 가장 많이 찾은 사람이 우승
- 플레이어끼리 서로의 캐릭터가 실시간으로 보임

## 힌트
- 남은 시간 3분부터 활성화
- 아직 안 찾은 보물에 가까울수록 효과음이 빨라짐
- 화면 가장자리 발광(시각 힌트) 병행 (iOS 브라우저는 진동 미지원)

## 큰 화면 (관리자 화면)
접속자 수, 시작 버튼, 실시간 순위, 남은 시간

## 성공 기준
40명이 끊김 없이 동시 접속해 15분을 끝까지 플레이하고, 마지막에 순위가 나온다.

## 제약
- 무료 CC0 로우폴리 에셋만 사용 (Kenney, Quaternius 등), 스타일 통일
- 중저가 폰에서도 부드럽게 동작
- 실시간 서버 필요, 무료 또는 저렴한 호스팅

## 하지 않을 것 (Out of scope)
- 로그인 및 회원가입
- 채팅
- 캐릭터 커스터마이징
- 플레이어 간 충돌이나 방해
- 기록 저장
- 점수 차등
- 보물 리스폰이나 단계별 투하
- 보물과 실제 경품 연결 (게임 밖에서 처리)
