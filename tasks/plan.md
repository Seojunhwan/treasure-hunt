# Implementation Plan: 송년 보물찾기 V1

겨울 마을 V1의 구현 계획이다. 현재 사무실 버전은 [기획 문서](../SPEC.md)와 [작업 목록](todo.md)의 첫 부분에서 이어간다. 당시 `SPEC.md`는 `git show ff056e2:SPEC.md`로 볼 수 있다.

## Overview
폰 브라우저용 3인칭 3D 멀티플레이 보물찾기. Node 서버 1개(localhost:8080, 사내 프록시 뒤)가 게임 화면, 관리자 화면, Socket.IO를 모두 서빙한다. 임시 도형으로 기능 전체를 먼저 완성(PoC)하고, 그다음 에셋과 맵을 고도화한다.

## Architecture Decisions
- **서버 권위 + 클라이언트 이동**: 이동은 각 폰이 직접 계산하고 10Hz로 보고, 획득/타이머/점수/순위는 서버가 결정. 40명 규모에서 가장 단순하면서 선착순 판정이 정확하다.
- **규칙은 server/game.js 순수 함수**: 소켓 없이 Vitest로 시간까지 가짜로 넣어 테스트한다.
- **맵 데이터는 shared/map.js 하나**: 충돌 박스, 스폰 광장, 보물 좌표를 서버와 클라이언트가 같이 읽는다. 고도화 때 도형이 모델로 바뀌어도 이 파일 구조는 유지.
- **위험한 것부터**: 프록시 경유 WebSocket, 실기기 성능, 45명 부하를 Phase 1에서 바로 검증한다.
- **게임 시간은 GAME_SECONDS 환경변수로 줄일 수 있게**: 수동 테스트와 리허설을 15분씩 기다리지 않기 위해. 기본값 900초.

## Risks and Mitigations
| Risk | Impact | Mitigation |
|------|--------|------------|
| 사내 프록시가 WebSocket을 막음 | High | Task 1에서 바로 확인. 막히면 롱폴링으로 동작은 하니 지연을 재고, 프록시 설정 변경 요청 |
| 캐릭터 40개 애니메이션이 중급 폰에서 무거움 | High | Task 12에서 실측. 넘치면 먼 캐릭터는 애니메이션 정지, 이름표는 가까운 사람만 |
| iOS는 사용자가 탭하기 전엔 소리를 못 냄 | Med | 입장 버튼 탭 시 AudioContext를 켜둠. 무음 모드 대비로 발광 힌트 병행 |
| 폰 화면 잠금으로 연결 끊김 | Med | 토큰 재접속(Task 4) + 화면 꺼짐 방지(Wake Lock API, 지원 브라우저만) |
| 여러 에셋 팩을 섞으면 스타일이 따로 놂 | Med | Task 11에서 팩을 1~2개로 제한하고 비교 화면으로 승인 받기 |
| 큰 텍스처로 iOS Safari 메모리 초과 크래시 | Med | Task 15에서 텍스처 해상도 상한, 압축 |
