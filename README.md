# 송년 보물찾기

채널클랜 송년회에서 약 20~30명이 즐길 3D 웹 게임이에요. 폰이나 노트북 브라우저로 사무실과 라운지를 돌아보며 응모권을 모아요. 관리자는 관리자 페이지를 큰 화면에 띄워 게임을 진행해요.

- 기본 회차는 15분이에요. 공유 응모권 20장과 개인 응모권 1인당 4장을 찾을 수 있어요.
- 회차가 끝나면 관리자 화면에서 참가자별 획득 장수를 확인해요. 실물 선물은 별도로 추첨해요.

현재 규칙은 [게임 스펙](SPEC.md)과 [응모권 획득 조건](보물찾기.md)에 정리했어요.

## 준비물

- 서버를 띄울 컴퓨터 1대 (Node.js 24 이상). 큰 화면에 관리자 페이지를 띄울 노트북이면 충분해요
- 참가자 기기: 폰(가로 모드 전용) 또는 노트북 브라우저

## 처음 한 번: 설치와 빌드

```bash
npm install
npm run build
```

## 행사 당일 순서

### 1. 서버 실행

```bash
ADMIN_TOKEN=원하는-비밀값 npm start
```

터미널에 이렇게 나와요.

```
players: http://172.30.1.44:8080          ← 참가자 접속 주소 (QR에도 이 주소가 들어가요)
admin:   http://localhost:8080/admin?token=…  ← 관리자 주소
game length: 900s
```

- `ADMIN_TOKEN`을 비우면 실행할 때마다 무작위 값이 만들어져요. 터미널에 찍힌 관리자 주소를 그대로 쓰면 돼요.
- 관리자 토큰은 참가자에게 보여주지 마세요. 관리자 주소를 아는 사람은 누구나 게임을 시작하거나 리셋할 수 있어요.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 8080 | 서버 포트 |
| `ADMIN_TOKEN` | 무작위 | 관리자 페이지 비밀값 |
| `GAME_SECONDS` | 900 | 한 판 길이(초) |
| `PUBLIC_URL` | 이 컴퓨터의 내부 IP | 참가자 접속 주소 기본값. 큰 화면에서도 바꿀 수 있어요 |

### 2. 큰 화면에 관리자 페이지 띄우기

터미널에 나온 `admin:` 주소를 브라우저에서 열고 전체화면(F11 / ⌃⌘F)으로 띄워요.

### 3. 참가자 접속 주소 확인

큰 화면의 QR 옆 주소가 참가자가 실제로 들어올 수 있는 주소인지 확인해요.

- 사내 프록시를 거쳐 들어와야 하면 **주소 수정**을 눌러 프록시 주소(예: `https://treasure.사내도메인`)를 넣고 저장하세요. QR이 바로 바뀌고, 서버를 다시 켜도 유지돼요.
- 칸을 비우고 저장하면 기본 주소로 돌아가요.
- 프록시는 WebSocket(`/socket.io/`)을 통과시켜야 해요. 막혀 있어도 느린 방식(polling)으로 이어지지만 움직임이 덜 부드러워요.

### 4. 참가자 입장

참가자는 QR을 찍거나 주소를 입력하고 닉네임을 넣어 입장해요.

- 시작 전에는 스폰 광장 안에서만 움직일 수 있고, **게임 방법** 카드가 자동으로 한 번 떠요.
- 게임 방법을 닫고 입구 근처의 **zinga.k**에게 다가가면 시작 전에도 말을 걸 수 있어요.
- 아이폰은 Safari 공유 버튼 → **홈 화면에 추가** 후 홈 화면 아이콘으로 열면 주소창 없이 전체화면이 돼요. 입장 화면에 안내가 나와요.
- 안드로이드는 입장할 때 자동으로 전체화면이 돼요.
- 새로고침하거나 폰이 잠겨도 같은 서버에 재접속하면 닉네임·응모권·위치가 복원돼요.

### 5. 시작 → 진행 → 종료

1. 큰 화면에서 **시작**을 누르면 zinga.k의 인사와 선물 투하 연출이 약 6.5초 동안 나와요. **출발!**이 뜨면 쪽지를 열 수 있고 타이머가 돌아요.
2. 큰 화면에는 참가자별 응모권 장수, 전체 합계, 공유 응모권 획득 현황이 나와요. 마지막 1분에는 타이머가 빨개져요.
3. 시간이 끝나면 최종 장수를 확인해 외부 추첨에 사용해요. 0장인 참가자도 목록에 표시돼요.
4. **리셋**을 누르면 새 회차를 준비해요. 획득 기록은 리셋이나 서버 종료 전에 확인해 주세요.

## 조작법

| | 폰 | 노트북 |
|---|---|---|
| 이동 | 화면 왼쪽을 누르고 끌기(조이스틱), 끝까지 밀면 달리기 | WASD 또는 방향키 |
| 시점 | 화면 오른쪽 끌기 | 화면 끌기. **자유 시점** 버튼이나 우클릭으로 마우스 이동만으로 시야를 돌리고, Esc로 해제 |
| 점프 | 오른쪽 아래 **점프** 버튼 | Space |
| 리더와 대화 | 가까이 가면 나오는 **말 걸기** 버튼 | 가까이 가서 **F** |
| 쪽지와 책상 살펴보기 | 가까이서 바라보고 **살펴보기** 버튼 | 가까이서 바라보고 **F** |

사무실에서는 천장을 생략한 3인칭 시점을 사용해요. 쪽지는 업무석, 통로, 라운지에 놓여 있어요. 점프는 약 1.3m 높이까지 올라가요.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 폰에서 접속이 안 돼요 | 폰과 서버가 같은 네트워크인지, 프록시 주소라면 큰 화면 주소가 맞는지 |
| 관리자 페이지에 "토큰이 올바르지 않습니다" | 서버를 다시 켰다면 토큰이 바뀌었을 수 있어요. 터미널의 `admin:` 주소로 다시 접속 |
| 시작 버튼이 안 눌려요 | 회차가 이미 진행 중인지 확인하고, 끝난 회차는 최종 장수를 확인한 뒤 리셋 |
| “연결을 확인하고 다시 눌러 주세요”가 떠요 | 같은 브라우저에서 게임 탭을 여러 개 열었다면 최근에 접속한 탭으로 돌아가거나 기존 탭을 닫고 새로고침 |
| 폰이 버벅여요 | `?debug`로 FPS를 확인하세요. 빛 번짐을 직접 켜둔 경우 `?post=0`으로 끌 수 있어요 |
| 소리가 안 나요 | 오른쪽 위 스피커 버튼, 폰의 무음 스위치 |

## 개발

```bash
ADMIN_TOKEN=devtoken GAME_SECONDS=600 npm run dev   # Vite 핫리로드 포함, :8080
npm test                                           # 규칙·맵·충돌 테스트
npm run loadtest -- --url http://localhost:8080 --bots 45 --seconds 60   # 봇 부하 테스트
```

- `?debug`를 붙이면 fps와 연결 방식이 보여요. fps 표시를 누르면 빛 번짐 효과를 켜고 꺼요.
- Kenney 에셋(CC0)과 Jua 글꼴(SIL OFL)의 출처는 [라이선스 목록](client/public/assets/LICENSE.md)에 있어요.

## 사무실 맵 둘러보기

상세 구성과 겨울 맵 전환 방법은 [사무실 맵 안내](docs/office-map.md)를 확인하세요. 설치·빌드 없이 사무실 씬만 확인하려면 `python3 scripts/preview-office.py`를 실행하고 안내된 로컬 주소를 여세요. 미리보기는 Three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다. 실제 게임은 기존 npm 개발·실행 명령을 사용합니다.
